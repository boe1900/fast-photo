# 发版检查清单

## 发布前

1. 工作区干净，分支与目标一致。
2. 执行后端测试：`cargo test`
3. 执行前端检查：`cd web && npm run lint && npm run build`
4. 执行端到端：`cd web && npm run test:e2e`
5. 备份数据库：`./scripts/backup_db.sh`

## 发布中

1. 停服务。
2. 部署新版本二进制与前端静态资源。
3. 启动服务并确认进程健康。

## 发布后

1. 冒烟验证：登录、时间线、上传、回收站、设置页。
2. 检查错误日志（启动后 10~15 分钟）。
3. 记录版本号、发布时间、回滚点。

## 回滚触发条件（建议）

1. 登录或首页不可用。
2. 上传/浏览主链路出现大面积 5xx。
3. 权限隔离回归（跨用户可访问）。

## 回滚步骤

1. 停服务。
2. 恢复数据库：`./scripts/restore_db.sh <backup-file>`
3. 恢复上一个稳定版本并重启。
